# App Ben (mobile): estrutura do código

Base: `packages/infra/mobile/ben`.

- `app/`: rotas do Expo Router (`index` é o login; o grupo `(protected)/` tem `chat`, `tasks/[taskId]`, `menu` e o `_layout` que guarda a autenticação).
- `src/api/`: camada de API (`client.ts` com axios para token nativo e `FormData`, `routes.ts`, `requests/`, `models/`, `responses/`, `types.ts`).
- `src/pages/`: telas por feature (`login`, `chat`, `task-workspace`, `menu`), cada uma com `components/`, `hooks/`, `stores/`, e o `chat` também com `states/` e `utils/`.
- `src/layout/strings/`, `src/pages/<feature>/strings/`: dicionários `*-strings.ts` por área (`Localized<T>` em `en` e `pt-BR`); `src/layout/hooks/use-strings.ts` (`useStrings`, `useLanguage`), `src/layout/utils/get-strings.ts` (`getStrings`) e `src/layout/stores/language-store.ts` (idioma atual, `hydrate`, `setLanguage`).
- `src/layout/`: primitivas de UI (`components/ui/`: `button`, `icon-button`, `switch`, `time-stepper`, `typography`...), componentes compostos (`chat-input`, `chat-banner`, `menu-*`, `alarm-popup/`, `daily-summary/`, `icons`, `brand-mark`...), hooks entre páginas, stores globais e utils (`colors` (hexes dos tokens para props de ícone), `format-time`, `styles` com `cn()`).
- Preferências do servidor: `src/api/models/user-preferences.ts`, `src/api/requests/user-preferences.ts`, `src/layout/stores/user-preferences-store.ts`, `src/layout/hooks/{use-user-preferences,use-user-preferences-sync,api/use-user-preferences-data}.ts`; switch em `src/layout/components/ui/switch.tsx` e seção em `menu-settings/usd-cost-section.tsx`; rodapé de custo em `src/pages/chat/components/message-footers/cost-footer.tsx`.
- Chat (`src/pages/chat/components/`): `chat-top-bar`, `active-task-peek` e `task-picker/` (faixa de tarefas), `chat-history/` (`chat-history`, `chat-history-item`), `day-divider/`, `message-bubble/`, `voice-wave/`, `capture-card/` (`root`, `icon`, `body`, `title`, `meta`, `dog-ear`, `action-button`), `message-footers/`, `message-trace-sheet/`, `chat-footer/`; `hooks/use-chat-list.ts` monta a lista com divisores e `utils/format-short-date.ts` formata a data curta.
- Lembretes e alarmes: `src/layout/hooks/{use-alarm-scheduler,use-daily-summary}.ts`, `src/layout/hooks/api/use-active-reminders-data.ts`, `src/layout/stores/alarm-store.ts`, `src/layout/strings/alarm-strings.ts`, `src/api/requests/reminders.ts`, push remoto em `src/layout/hooks/use-push-device-registration.ts`, `src/api/requests/push-devices.ts`, `src/api/models/push-device.ts` e `menu-settings/test-notification-button.tsx`, `src/storage/daily-summary-storage.ts`, `menu-reminders/` e `menu-detail/reminder-editor.tsx`.
- `src/storage/`: persistência nativa. `expo-secure-store` (token, com cache síncrono em memória) e AsyncStorage (usuário e idioma, `language-storage.ts`, chave `@ben/language`). Arquivos `*.web.ts` cobrem o web.
- `src/services/`: fronteira com SDKs nativos (`audio-service`, `clipboard-service`, `google-auth-service`, `notifications-service`, este o único importador de `expo-notifications`; canais, agendamento, toques e `getExpoPushToken`). Arquivos `*.web.ts` são a versão web (`audio-service.web.ts` grava com `MediaRecorder`; `notifications-service.web.ts` é no-op). Testes Vitest em `src/services/__tests__/`.
- `src/core/`: ligação do app (`languages.ts` com `LANGUAGES`, `Language`, `DEFAULT_LANGUAGE`, `LANGUAGE_LOCALES`, `LANGUAGE_LABELS`, `Localized`; `env`, `query-client`, `routes`, `firebase`, `auth-bootstrap` (também hidrata o idioma), `logger`, `runtime`, `global.css`) e `app-versions.ts`: lista `APP_VERSIONS` (a primeira entrada é a atual) e `CURRENT_APP_VERSION`, lida pelo `app.config.ts` para o campo `version` do Expo e pela folha de configurações (`src/layout/components/menu-settings/app-versions-section.tsx`).
- Fora de `src/`: `app.config.ts` (importa `./src/core/app-versions.ts` com extensão explícita, o que exige `allowImportingTsExtensions` no `tsconfig.json`), `eas.json`, `tailwind.config.js`, `metro.config.js`, `babel.config.js`, `vitest.config.ts`, `google-services.json`, `scripts/` (ícones e ambiente Android), `plugins/`, `assets/`, `android/`, `credentials/`.

Os tokens de fonte (`wordmark`, `tagline`, `headline-lg`, `body-md`, `button`, `label-caps`, `code`) e as famílias `font-sans*` estão em `src/layout/components/ui/typography.tsx` e `tailwind.config.js`.
